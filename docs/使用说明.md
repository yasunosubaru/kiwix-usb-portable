# Kiwix 离线维基 · 便携版（U 盘整合包）

一个 U 盘 = 一套完整的离线维基百科服务器。**不安装、不联网、不依赖 Docker。**

- kiwix-tools **3.8.2**（官方静态二进制，非自己编译）
- 内置：Linux x86_64 / Windows 程序、GUI 启动器、Docker 离线镜像、命令行脚本
- 浏览器打开即用，支持全文搜索

---

## 快速开始

### Windows
双击 **`start-gui.cmd`** → 出现 GUI → 点「▶ 启动服务」→ 自动打开浏览器。

### Linux 桌面环境（有图形界面）
```bash
chmod +x app/gui/KiwixUSB-linux-x86_64
./app/gui/KiwixUSB-linux-x86_64
```
> 该二进制在 **Debian 12 / glibc 2.36** 基线上构建（与飞牛 fnOS 相同），
> 实测最高只依赖 `GLIBC_2.36`，所以 Debian 12、Ubuntu 22.04+、飞牛 fnOS 都能加载。
> 但它**需要图形显示（X11/Wayland）**；无桌面的环境请用下面的命令行方式。
> 缺 X11 库时：`sudo apt install -y libx11-6 libxext6 libtk8.6 libxrender1`

### Linux / 飞牛 fnOS（无桌面，只有 SSH）→ 走这一条
```bash
chmod +x start.sh stop.sh
./start.sh
```

### 飞牛 fnOS：让服务长期常驻（推荐）
见下面「飞牛 fnOS：让服务常驻」一节，用 `install-fnos.sh` 装进 Docker。

## GUI 能做什么

| 功能 | 说明 |
|---|---|
| **启动前预检** | 架构 / 程序 / 内容库 / 端口 / 可用内存，五项一目了然 |
| **一键启停** | 启动后自动显示局域网地址，并打开浏览器 |
| **自动避让端口** | 端口被占用时改用下一个，**不会结束别人的进程**，并在日志里说明 |
| **运行状态** | PID、已运行时长、本机健康检查（每 3 秒） |
| **完整性校验** | 点「校验完整性」才计算 SHA256（约 3 分钟 / 145GB），对照包内基线 |
| **显式错误提示** | 秒退、架构不符、内存不足、资料库缺失都给出可执行的下一步 |
| **飞牛常驻部署** | 一键复制 `install-fnos.sh` 命令 |

### 刻意不做的事（安全边界）

- ❌ 不静默提权、**不要求管理员权限**
- ❌ 不创建系统自启项、不写注册表、不改防火墙
- ❌ 不联网、不自动更新、不上报任何数据
- ❌ 不修改 / 移动 / 重写 ZIM（**始终只读**）
- ❌ 启动时不做全盘哈希扫描（145GB 扫描会拖慢启动）
- ❌ 日志不含搜索词与浏览记录（未开启 `--verbose`）
- ❌ 关闭 GUI 会停止它启动的服务，不留孤儿进程

## 飞牛 fnOS：让服务常驻

**纯 U 盘模式有个硬限制：U 盘必须一直插着，而且很多系统会把 U 盘以 `noexec` 挂载（那样连 GUI 都启动不了）。**
所以要在 NAS 上长期提供服务，正确做法是装进 NAS：

1. 插 U 盘到飞牛
2. **设置 → SSH** 开启；**设置 → 用户管理 → 你的账号 → 更多 → 启用 SSH**（两个都要）
3. SSH 进去，切到 U 盘目录：
   ```bash
   sudo sh install-fnos.sh
   ```
4. 脚本会：把 145GB ZIM 复制到 `/vol1/1000/kiwix/zim/` → 导入离线镜像 → 启动容器（`--restart unless-stopped` 开机自启）

> 目标路径里的 `1000` 是飞牛的默认用户 ID。若你的不是 1000，
> 用「文件管理 → 右键 kiwix → 详细信息 → **复制原始路径**」确认真实路径，再改脚本第 17 行。

也可以直接用飞牛的 **计划任务 → 用户定义的脚本**，避免开 SSH。

## 外网访问

⚠️ **kiwix-serve 本身没有任何登录功能**，直接暴露到公网等于「拿到网址的人都能看」。

推荐顺序（详见 `Kiwix-NAS-部署方案.md` 第 5 节）：

1. **Tailscale** — 不开任何公网端口，只有自己和家人能访问
2. **Cloudflare Tunnel** — 想要公网网址时用；建议再加一层邮箱验证
3. **飞牛应用中心的 Lucky** — DDNS + 反代 + 内网穿透一个应用搞定
4. 公网 IP + 443 端口映射 + 反向代理

不要把服务端口直接映射到公网 `0.0.0.0` / IPv6 `::`。

## 常见问题

**Q：双击没反应 / 闪退？**
A：Windows 上如果被安全软件拦截会有提示。确认文件来自你自己拷贝的整合包；本应用不要求管理员权限，也不需要你关闭防护。

**Q：提示「不支持的架构」？**
A：本整合包内置 x86_64（绝大多数飞牛/迷你主机都是）。ARM 机型需要补 aarch64 组件。

**Q：打开网页只有中文维基，英文维基不见了？**
A：不是文件丢了，是 **kiwix 首页脚本按「浏览器界面语言」自动加了语言过滤**：
`/skin/index.js` 里 `if (!window.location.hash) { ...按 navigator.language 自动选中语言... }`，
中文浏览器就会只显示 `zho` 那本，而且过滤状态会写进 cookie **保留一整天**。

解决（任选）：
- 点本程序的 **「打开书架（全部）」** 按钮（它会自动带 `#lang=` 跳过过滤）
- 手动访问用 `http://IP:端口/#lang=`
- 或把页面顶部语言下拉改成 **All languages** 再刷新

确认服务器到底加载了几本：访问 `http://IP:端口/catalog/v2/entries`，
里面 `<entry>` 的条数就是实际加载的书目数。本程序启动后也会自动做这项自检，
状态栏会显示「已加载 2/2 本」。

**Q：启动后书架是空的？**
A：99% 是 `zim/` 里没有 `.zim` 文件，GUI 会在预检条上直接显示「未放入 .zim」。

**Q：搜索很慢？**
A：118GB 英文维基的全文搜索确实吃 CPU、内存和磁盘带宽。这台机器的 CPU/内存越强、存储越快，搜索越快。

**Q：换了新版 ZIM？**
A：删旧放新。GUI 模式点「停止 → 启动」即可；Docker 模式 `docker restart kiwix`。

**Q：U 盘里的文件会被改吗？**
A：不会。ZIM 始终只读打开，本应用不写入、移动或重写任何 ZIM 内容。
